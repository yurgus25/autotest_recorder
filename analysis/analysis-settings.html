Значение или паттерн
Примеры паттернов:
• "Авто*" → "Автомобиль", "Автор", "Авто80"
• "Test?" → "Tests", "Test5"
• "User{5}" → "Userab12c" (точно 5 символов)
• "Code{3-8}" → "Code12345" (от 3 до 8 символов)
• "Test[123]" → "Test2" (один из символов)
• "{email}" → "random@gmail.com"
• "{phone}" → "+7 (999) 123-45-67"
• "{digit}{digit}{digit}" → "582"
• "{uppercase:test}" → "TEST"
