## 1. Кто отвечает за расширение

**AutoTest Recorder & Player** — расширение для браузера, предназначенное для записи и воспроизведения автоматизированных тестовых сценариев на сайтах. ## 2. Какие персональные или конфиденциальные данные собираются

Расширение является **инструментом QA / автоматизации тестов**. В ходе записи и воспроизведения обрабатываются данные на страницах, **которые вы открываете и выбираете для тестирования**. Это может включать данные из категорий, признанных конфиденциальными политиками Chrome Web Store:

| Категория | Что обрабатывается | Где хранится |
|-----------|-------------------|--------------|
| **Содержимое страниц и взаимодействия** | URL, селекторы элементов, вводимый текст, клики, навигация, фрагменты DOM для шагов теста | Локально в браузере |
| **Данные форм** | Значения полей, записанные в сценариях или передаваемые через переменные / строки CSV | Локально в браузере |
| **Сетевые метаданные** | При включённом мониторинге сети: URL запроса, метод, тип, время, код ответа, ошибки. **Тела запросов и ответов не собираются** для неконтекстных целей. | Локально в браузере |
| **Скриншоты и видео** | Полноразмерные снимки страницы и видео прогона создаются **по вашей команде** (шаг или команда теста) и сохраняются в папку «Загрузки» | Локально; перемещаются в «Загрузки» по вашему действию |
| **Буфер обмена** | Значения, копируемые/вставляемые в интерфейсе тестирования или шагах сценария | Используются в памяти; никуда не отправляются |
| **JavaScript, написанный пользователем** | Код, введённый в редакторе, выполняется **локально** при прогоне теста | Только локально |

Расширение **не предназначено** для сбора данных в рекламных целях, перепродажи профилей пользователей или скрытого отслеживания, не связанного с автоматизацией тестов.

## 3. Как данные используются

Данные, обрабатываемые расширением, используются **исключительно** для:

- Записи, редактирования, хранения и воспроизведения ваших тестовых сценариев.
- Отображения отчётов, журналов, скриншотов, сетевых метрик и данных о производительности **в интерфейсе расширения**.
- Выполнения шагов сценария на страницах, которые вы выбрали для тестирования.
- Опциональных функций (запись видео, мониторинг сети, прогоны по CSV) строго в объёме, описанном в интерфейсе и в этой политике.

---

## 4. Где и как долго хранятся данные

- **Место хранения:** Локально в браузере через `chrome.storage.local`. Расширение **не использует** `chrome.storage.sync`, поэтому тесты и настройки **никогда** не отправляются в Chrome Sync или облачный сервис через этот API.
- **Срок хранения:** Данные хранятся до тех пор, пока вы не удалите тесты / настройки через интерфейс расширения, не очистите данные расширения в настройках Chrome или не удалите расширение.
- **Обязательная облачная учётная запись** у издателя не создаётся просто по факту установки расширения.

## 5. Кому передаются данные

| Получатель | Передаются ли данные |
|------------|----------------------|
| **Серверы издателя** | **Нет.** Содержимое тестов, пароли сайтов и HTML-код страниц **никогда** не загружаются на наши серверы как условие использования расширения. |
| **Google / браузер Chrome** | API расширений работают внутри Chrome в соответствии с политиками Google. Используется только `chrome.storage.local` — **без Chrome Sync**. См. [Политику конфиденциальности Google](https://policies.google.com/privacy). |
| **Сайты и API, которые вы задаёте** | **Да, по вашему выбору.** При выполнении сценария, открывающего URL, отправляющего форму или вызывающего API, браузер делает обычные запросы к этим адресам. Используйте HTTPS там, где это требует сервис. |
| **Рекламные и аналитические сети** | **Нет** встроенной передачи данных в рекламные или аналитические сервисы по умолчанию. Любые будущие опции opt-in аналитики будут раскрыты здесь и в интерфейсе перед активацией. |
| **Сервер проверки лицензии (опционально)** | В публикуемой сборке `remoteCheckUrl` = `null` — удалённая проверка лицензии не выполняется. Если будет включена в будущем обновлении, здесь будут описаны только данные, фактически отправляемые этим запросом. |

Мы **не продаём** данные пользователей и не передаём их в целях, не связанных с автоматизацией тестов.

## 6. Безопасность

- Локальные данные защищены моделью безопасности расширений Chrome и операционной системой.
- Сетевые запросы, инициируемые вашими тестовыми сценариями, используют стандартный сетевой стек браузера; применяются политики безопасности Chrome (например, требования HTTPS).
- Сотрудники издателя **не получают доступ** к содержимому ваших тестов или данным страниц на вашем устройстве.

## 7. Ваши права и управление данными

- **Просмотр и управление данными:** откройте popup расширения → список тестов, Настройки.
- **Экспорт данных:** используйте встроенную функцию экспорта для скачивания тестов в JSON.
- **Удаление данных:** удаляйте отдельные тесты в popup или используйте *Удалить все данные*. Для полной очистки удалите расширение и очистите его хранилище в Настройки Chrome → Конфиденциальность и безопасность → Настройки сайта → Просмотр разрешений и данных.
- **Учётная запись не требуется:** основные функции работают без создания учётной записи у издателя.

## 11. Соответствие Chrome Web Store — Limited Use

**Обязательное подтверждение (формулировка Google):**
> *The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.*

В контексте этого расширения «информация из Google API» включает данные, обрабатываемые через API платформы расширений Chrome (вкладки, хранилище, сеть, отладчик, скрипты и др.) в рамках заявленных функций.

**Сводка по Limited Use:**

- Данные, собираемые через API Chrome, используются **только** для предоставления и улучшения единственной узкой цели продукта: записи, редактирования и воспроизведения веб-тестов — как описано в карточке магазина и интерфейсе расширения.
- Активность в сети (URL, метаданные запросов) используется **только** в объёме, необходимом для этих пользовательских функций — **не** для персонализированной рекламы, **не** для продажи брокерам данных, **не** для оценки кредитоспособности и других запрещённых целей.
- Любая передача третьим лицам осуществляется только там, где это разрешено политикой Google (например, необходимость для заявленной функции, требование закона, защита от злоупотреблений) или явно описано в разделе 5.

## 12. Единственное назначение расширения

**AutoTest Recorder & Player** — инструмент для автоматизации веб-тестирования: записывает действия пользователя на сайтах по его выбору, позволяет редактировать тесты в визуальном редакторе и воспроизводить их с проверками, журналами и отчётами. Не предназначен для сбора данных с сайтов в рекламных или иных целях, не связанных с тестированием.

## 13. Обоснование разрешений

| Разрешение | Зачем нужно |
|------------|-------------|
| `<all_urls>` | Тесты выполняются на URL по вашему выбору — внутренние стенды, localhost, SaaS и т.д. Перечислить все домены заранее невозможно. |
| `debugger` | Полноразмерные скриншоты через DevTools Protocol (attach → снимок → detach). Не используется для удалённого управления третьими лицами. |
| `tabCapture` | Запись видео прогона теста из выбранной вкладки в файл по инициативе пользователя. |
| `webRequest` | Сбор метаданных запросов (URL, статус, время) во вкладке при включённом мониторинге сети; не для модификации трафика в рекламных целях. |
| `offscreen` | Обработка медиапотока вкладки для записи видео согласно требованиям Manifest V3. |
| `storage` | Локальное хранение тестов, настроек и журналов прогонов. |
| `activeTab`, `scripting`, `tabs` | Доступ к активной вкладке по жесту пользователя; внедрение скриптов для записи/воспроизведения; перечисление и переключение вкладок в многовкладочных сценариях. |
| `downloads` | Сохранение экспортируемых файлов (отчёты, JSON тестов, скриншоты, видео) в папку «Загрузки» по команде пользователя. |
| `windows` | Открытие окон редактора и полноэкранного режима; чтение и закрытие служебных окон расширения. |
| `clipboardRead` / `clipboardWrite` | Шаги сценария и UI, связанные с копированием/вставкой значений (например, значения полей, копирование селекторов). |
