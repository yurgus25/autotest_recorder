## [0.9.7.2] — 2026-04-01

**Первые пункты roadmap (этап роста продукта)** — для превью доступны всем; часть позже уйдёт в Premium.

### Data-driven (CSV / таблицы)

- Прогон одного теста по строкам CSV с подстановкой значений в контекст переменных; лимит строк для базового режима; фоновая очередь и итоговая сводка по строкам.
- **Экспорт отчёта** в CSV (pass/fail по строкам, UTF‑8 BOM) из редактора — задел под платную расширенную аналитику.

### Visual regression (lite)

- Эталоны сравнения хранятся в **`extensionAssets.visualRegressionBaselines`** внутри JSON теста (удобно переносить между машинами); при импорте в будущем можно будет не подтягивать этот блок.
- Плеер: сначала чтение из теста, fallback на прежнее хранилище `chrome.storage.local`; обновление эталона через **`MERGE_TEST_EXTENSION_ASSETS`**.
- Сохранение теста из редактора (**`UPDATE_TEST`**) **сливает** `extensionAssets` с уже сохранённым тестом, чтобы не затирать эталоны, записанные во время прогона.

### Онбординг и шаблоны

- Мастер первого запуска в popup и стартовые шаблоны.
- В **настройках** — пункт **«Показать снова»**: сброс флага завершения мастера (`onboardingWizardV1CompletedAt`).

### Прочее

- Заготовки feature flags: **`DATA_DRIVEN_BULK`**, **`VISUAL_REGRESSION_LITE`** (пока с `fallbackEnabled: true` для теста).

## [0.9.7.0] — 2026-03-29

**Сборка для GitHub** — набор функций и исправлений, которых **нет** в последней опубликованной версии в Chrome Web Store (актуально на дату релиза).

### Запись и селекторы (dropdown, Angular)

- **Кастомные выпадающие списки (Angular `app-select`, CDK Overlay):** надёжнее связывается панель в `.cdk-overlay-container` с нужным полем; уточнено, что пункты в overlay / content-list — это опции списка, а не пункты меню Wicket.
- **Отличие меню приложения от combobox:** пункты GWT-стиля (`role="menu"`, gwt-Menu, ссылки в Popup и т.п.) не записываются как «ввод» в чужой `mat-select` / `rc_select`; клик по пункту меню — шаг **click**, не ложный **input**.
- **Целевое поле при записи dropdown:** `resolveToDropdownRoot`, привязка polling и верификации к одному открытому полю; увеличен порог дистанции для overlay-панелей (связь с правильным `app-select` на длинных формах).
- **Ложные input из polling / `resolveDropdownFill`:** проверки `shouldRejectDropdownValueForFieldMismatch`, отмена polling при клике по пункту меню; узкая эвристика опций (без общего `.item` как у GWT).
- **Стабильные селекторы для `app-select`:** приоритет `app-select[elementid="…"]` и вариантов с `label` в генерации селекторов; снижен вес нестабильного блока `angular-component` для дубликатов.

### Воспроизведение (player)

- **Расширенная логика dropdown / fill-fields** в `player-handlers-extended.js` (и смежные модули): автоматический выбор значения, сценарии в стиле fill-fields для кастомных списков, обход панелей CDK, приоритет кликов по `.select-box` / контейнерам результата, повторное открытие списка при необходимости.
- **Повтор заполнения по альтернативным селекторам** (`retryFillWithAlternativesOrThrow`) при несовпадении ожидаемого значения.
- **XPath → CSS:** общий fallback `_xpathIdPathToCssFallback` для путей вида `//tag[@id='…']/…`; больше попыток `findElementWithRetry` в критичных местах (5 вместо 2).
- **Ввод:** устранение «Illegal invocation» при нативной установке значения (`setNativeInputValue` + fallback).

### Инфраструктура и UX

- **Service Worker / инжект скриптов:** в списках файлов для инжекта используются реальные `player-core.js`, `player-handlers-*.js`, `player-init.js` (исправлены ошибки «fetching the script»).
- **Анализатор селекторов:** выбор **любой открытой вкладки** в выпадающем списке (не только текущая).
- **Справка и полноэкранный popup:** обновления разделов про инспектор селекторов и удобство доступа к расширенному поиску.
- **Хранилище:** мягкая обработка `quota exceeded` при сохранении истории прогонов и состояния воспроизведения.
- **Очистка:** удалена отладочная инструментализация (локальные ingest / лишние `fetch`) из кода плеера.

### Прочее (из предыдущих итераций ветки 0.9.6.x)

- Группы тестов (premium), адаптивные шаги, импорт Katalon XML, улучшения скриншотов и popup — см. `changes.md` и `versions.txt`.

## Как собрать zip для GitHub Release

Из корня репозитория (Windows PowerShell):

```powershell
.\scripts\build-release.ps1
```

Архив: `dist/autotest-recorder-<version>.zip`, готов к загрузке в [Releases](https://github.com/yurgus25/autotest_recorder/releases).

Установка в Chrome: «Режим разработчика» → «Загрузить распакованное расширение» → папка распакованного архива (или клон репозитория).
