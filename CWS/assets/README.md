# Значок магазина (128 × 128 px)

## Готовый файл

- **`store-icon-128x128.png`** — копия [`icons/icon128.png`](../../icons/icon128.png) из корня расширения.

Загрузите его в поле **«Значок магазина»** в консоли разработчика.

## Требования

- Размер **128×128** пикселей.
- Формат: PNG, JPEG или соответствующие требованиям текущей версии консоли (без запрещённых элементов: бренды чужих продуктов без прав, вводящие в заблуждение изображения).

Если обновите иконку в `icons/`, пересоберите копию в эту папку:

```powershell
Copy-Item ..\icons\icon128.png .\store-icon-128x128.png -Force
```

(Из корня репозитория, находясь в `CWS/assets`.)
