# Скриншоты для Chrome Web Store

## Требования магазина

- **Количество:** 1–5 шт.
- **Размер:** **1280 × 800** или **640 × 400** px.
- **Формат:** JPEG или **24-бит PNG без альфа-канала** (файлы ниже — RGB PNG).

## Готовые файлы (из `Desktop\ат-проверка`, обработаны скриптом)

| Файл | Размер | Исходник |
|------|--------|----------|
| `01-screenshot-640x400.png` | 640×400 | `640.png` |
| `02-screenshot-1280x800.png` | 1280×800 | `Screenshot_1.png` |
| `03-screenshot-1280x800.png` | 1280×800 | `editor.png` |
| `04-screenshot-1280x800.png` | 1280×800 | `editor_short.png` |
| `05-screenshot-1280x800.png` | 1280×800 | `plugin.png` |

Подгонка: масштабирование с **обрезкой по центру** до точного размера, фон вместо прозрачности — белый.

Пересборка из той же папки на рабочем столе:

```text
python scripts/build-cws-images-from-folder.py
```

(из корня репозитория.)
