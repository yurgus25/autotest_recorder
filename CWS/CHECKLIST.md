# Чеклист: сведения о продукте (Chrome Web Store)

Отметьте по мере заполнения в [Developer Dashboard](https://chrome.google.com/webstore/devconsole/).

## Обязательные тексты

- [ ] **Название** — из пакета: `AutoTest Recorder & Player` (или совпадает с `manifest.json`)
- [ ] **Сводные данные** (краткое описание, ≤132 символов) — см. `02-package-fields.txt`
- [ ] **Описание** (до 16 000 символов) — вставить из `01-description-ru.txt` (и при необходимости `01-description-en.txt` для второго языка)

## Категория и язык

- [ ] **Категория** — рекомендуется **Developer Tools** / **Инструменты разработчика** (см. `03-metadata.json`)
- [ ] **Язык продукта** — указать язык интерфейса (расширение поддерживает RU/EN; см. `03-metadata.json`)

## Графика

- [ ] **Значок магазина** 128×128 — файл: `assets/store-icon-128x128.png` (копия из `icons/icon128.png`)
- [ ] **Скриншоты** — минимум 1, максимум 5; 1280×800 или 640×400; JPEG или 24-бит PNG без альфа — см. `screenshots/README.md`
- [ ] **Малое рекламное** 440×280 — см. `promo/README.md`
- [ ] **Очень большое рекламное** 1400×560 — см. `promo/README.md`
- [ ] **Глобальный проморолик** (опционально) — URL YouTube

## Дополнительные поля

- [ ] **URL главной страницы** — см. `04-urls.txt`
- [ ] **URL службы поддержки** — см. `04-urls.txt`
- [ ] **Политика конфиденциальности** — в разделе «Конфиденциальность» дашборда; URL на `PRIVACY_EN.md` или `PRIVACY.md` в репозитории (см. `04-urls.txt`)

## После загрузки пакета (.zip)

- [ ] Разрешения согласованы с текстом в `PRIVACY.md` и `05-permission-notes-ru.txt`
