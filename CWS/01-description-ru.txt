AutoTest Recorder & Player — расширение для Google Chrome (Manifest V3) для автоматизации веб-тестов без написания кода. Вы записываете действия на странице, при необходимости правите сценарий в визуальном редакторе и запускаете воспроизведение с умными ожиданиями, self-healing селекторами, логами и скриншотами.

ДЛЯ КОГО
• QA-инженеры и тестировщики, которым нужны быстрые регрессионные сценарии без Selenium-скриптов.
• Разработчики фронтенда, проверяющие сложные виджеты (выпадающие списки, мультиселект, autocomplete, Angular app-select и CDK Overlay).
• Команды, которым важны наглядные отчёты, история прогонов и экспорт данных.

ЗАПИСЬ
Автоматическое захватывание кликов, ввода, навигации. Умные селекторы (CSS, XPath, атрибуты), подстраховка при изменении вёрстки (self-healing). Поддержка сложных элементов интерфейса.

ВИЗУАЛЬНЫЙ РЕДАКТОР
• Drag & drop шагов, группы Quick Steps, переменные вида {var:name}.
• Условия, циклы, API-шаги (GET/POST с подстановкой переменных), шаги с пользовательским JavaScript для проверок (код задаётся вами в редакторе и выполняется локально при прогоне).
• Аналитика и расширенные сценарии — в зависимости от версии и настроек.

ВОСПРОИЗВЕДЕНИЕ
Умные ожидания, оптимизация скорости, детальные логи, скриншоты элементов и страницы. Опционально — запись видео прогона вкладки для отчётов и демонстрации дефектов.

АНАЛИТИКА И ИНСТРУМЕНТЫ
История прогонов, графики, экспорт (в том числе CSV). Анализатор селекторов, дашборды производительности и адаптивной аналитики, работа с настройками анализа — в интерфейсе расширения.

ТЕХНИЧЕСКИЕ СВЕДЕНИЯ
Тесты и настройки хранятся локально в браузере. Расширение рассчитано на работу на тех сайтах, которые вы сами открываете для проверки (включая корпоративные стенды и localhost); для этого нужен широкий доступ к сайтам, как указано в запросе разрешений. Детальное описание разрешений и политики данных — в политике конфиденциальности на странице репозитория (PRIVACY.md / PRIVACY_EN.md).

ЛИЦЕНЗИЯ И ИСХОДНЫЙ КОД
Лицензия MIT. Исходный код и релизы: GitHub (см. ссылку «Главная страница» в карточке магазина).

Преимущества: один инструмент для записи, редактирования и прогона; наглядность для команды; не требуется отдельный сервер для базовой работы; расширение соответствует современной модели Manifest V3.
