# Рекламные изображения (промо-плитки)

## Требования Chrome Web Store

| Тип | Размер (canvas) | Формат |
|-----|-----------------|--------|
| Малое рекламное изображение | **440 × 280** px | JPEG или 24-бит PNG без альфа |
| Очень большое рекламное изображение | **1400 × 560** px | JPEG или 24-бит PNG без альфа |

## Текущие файлы (брендированные)

Сгенерированы скриптом из иконки расширения и типографики (градиент, без альфа-канала):

| Файл | Размер |
|------|--------|
| **`promo-small-440x280.png`** | 440×280 |
| **`promo-large-1400x560.png`** | 1400×560 |

Пересборка после правок в `scripts/build-cws-promo-branded.py`:

```text
python scripts/build-cws-promo-branded.py
```

## Альтернатива: из скриншотов рабочего стола

Если нужны промо на основе своих PNG (обрезка по центру), используйте:

```text
python scripts/build-cws-images-from-folder.py
```

(путь к исходникам задаётся в скрипте.)
