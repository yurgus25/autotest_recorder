# Поля для карточки магазина (источник — Chrome i18n)

Имя и краткое описание берутся из **`_locales/<locale>/messages.json`** (`extName`, `extDescription`),
в `manifest.json` указаны `__MSG_extName__` и `__MSG_extDescription__`. Вводить их вручную в Dashboard
не нужно — CWS читает их из пакета расширения автоматически.

---

## Название (все локали)

AutoTest Recorder & Player

---

## Краткое описание EN (en, лимит 132 символа) — 128 симв.

No-code web test automation: record, visual editor, playback with smart waits & self-healing. Angular app-select, analyzer tabs.

---

## Краткое описание RU (ru, лимит 132 символа) — 126 симв.

Тестирование сайтов без кода: запись, редактор, прогон, умные ожидания и self-healing. Angular app-select, анализатор вкладок.
