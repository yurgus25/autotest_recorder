Короткие формулировки для ответов модерации или полей «обоснование» (см. также PRIVACY.md в корне репозитория).

all_urls / host_permissions
Нужен доступ к сайтам, которые пользователь сам открывает для тестов (стенды, localhost, продакшен); заранее перечислить домены невозможно.

debugger
Временное подключение DevTools Protocol для полноразмерного скриншота страницы по запросу пользователя в сценарии; не для удалённого управления третьими лицами.

tabCapture + offscreen
Запись видео прогона теста с вкладки в файл по действию пользователя (отчёты, демонстрация багов).

webRequest
При включённом сетевом мониторинге — метаданные запросов вкладки (URL, статус, время) для отчётов и анализа; не для рекламной модификации трафика.

storage / tabs / scripting / activeTab / downloads / windows / clipboard
Сохранение тестов и настроек, управление вкладками и окнами сценария, внедрение скриптов записи/воспроизведения, экспорт файлов, буфер обмена для шагов теста.

Пользовательский JavaScript в шагах
Выполняется только из сценариев, созданных пользователем в редакторе, локально при прогоне; расширение не подгружает исполняемый код с произвольных URL для обхода правил магазина.
